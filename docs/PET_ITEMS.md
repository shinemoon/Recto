# 书宠的行囊与银钱

> 这份文档只讲**一件事**: 那只书宠受伤之后怎么活下来。
> 它为什么需要这一层、钱从哪来、药怎么用、装具怎么进交手 —— 数字都能在代码里找到出处。
>
> 落点: `src/recto/pet/gear.py` (物件表与账) · `charsheet.py` (装具加成 / 上限)
> · `chronicle.py` (出门前 / 战后 / 路上的账) · 页面: `/pet/` 的「行囊与银钱」卡
> · 存档: `<pet_dir>/char.json` 的 `money` / `bag` / `equip` 三栏

---

## 0. 为什么要有这一层

交手是拿气血换的: 一场输下来能从 97 掉到 1。旧代码只在**回合末尾**回 18% 气血,
而"一刀砍掉半条命"追不上 —— 实测那只书宠卡在 `20/97` 整整两天, 故事里就成了
"永远带伤", 出场一次伤一次, 永远不会好。江湖上的人不是这么活的: 伤了要上药,
伤重了要找郎中、住客栈, 这些都要钱; 钱是路上挣来的。有了这一层, 气血才会在
60~95% 之间起伏, 而不是单调往下掉。

## 1. 三条恢复路径 (都有代价)

每到"这一趟"开始时 (`chronicle._run_locked` → `gear.selfcare`), 它按顺序自己料理:

| 顺序 | 做法 | 代价 | 触发条件 |
|---|---|---|---|
| 1 | **用行囊里的药 / 吃食** | 消耗那一份 (药 6~140 文买来的) | 气血 < 72% 或内力 < 55% 或精神 < 55% |
| 2 | **去医馆** (`CLINIC`, 45 文, 气血 +55% / 内力 +30%) | 45 文 | 气血 < 42% 且钱够 |
| 2 | **住客栈** (`INN`, 18 文, 气血 +30% / 精神 +30% / 内力 +20%) | 18 文 | 气血 < 62% 且钱够 |
| 3 | **打坐** (`charsheet.restore`, 约 +8% 气血 / +7% 内力) | 时间 (不花钱) | 气血 < 55% 或内力 < 40% |

- 打输那一场之后**再来一次** (「战后」那一步, 种子 +1) —— 所以"带伤回家上药"是真发生的。
- 气足 (气血 ≥72% 且内力/精神 ≥55%) 时**什么都不做**, 也不写账 —— 不是每回都吃药。
- 挑药的口径: 缺口最大的那一项 → 优先**药** (药治伤, 干粮只垫一口) → 够用且便宜的那份。
- 这一整套**纯后端结算**: 花了几文、敷了几包都在账上; 故事只负责把它写出来。

## 2. 钱从哪来 (`gear.aftermath`)

| 这一趟 | 收入 | 支出 |
|---|---|---|
| 斗 · 赢 | 18~55 文 (对手身上摸的) + 30% 概率一件战利品 | — |
| 斗 · 输 | — | 6~18 文 (钱袋被摸) + 15% 概率丢一包药 |
| 斗 · 平 | 0~11 文 | — |
| 救 | 16~45 文 (谢礼) + 20% 概率一件谢礼 | — |
| 行 | 5~16 文 (脚钱) + 15% 概率路边捡到 | — |
| 观 | 0~8 文 | — |
| 会 | 两不相欠 | — |
| 学 | — | 6~14 文 (买纸墨) |

- 战利品优先是**对手使的那一路兵刃** (使刀的掉柳叶刀 / 雁翎刀), 否则从常见杂物里挑。
- 所有随机都吃同一个种子 (`名字|故事日|语料`), 同一天重跑结果一致 —— 故事与账对得上。
- 钱夹在 `0 ~ MAX_MONEY` (99999), 不会被扣成负数。

## 3. 物件表 (`gear.ITEMS`)

六个类: **药** (敷的服的) / **吃食** / **兵器** / **护具** / **佩物** / **杂用**。
买价就是表里的 `price`, 卖价一律 `max(1, price // 3)`。

| 类 | 例子 | 作用 |
|---|---|---|
| 药 | 金创药 24 文 (气血 +35%) · 生肌散 58 (气血 +60%) · 回气丹 32 (内力 +70%) · 安神散 26 (精神 +55%) · 大还丹 140 (气血满 + 内力/精神) | 恢复状态, 用掉少一份 |
| 吃食 | 干粮 6 (气血 +8% / 精力 +30%) · 汤饼 10 · 烧刀子 12 (精神 +30%) | 便宜、回得少, 救急 |
| 兵器 | 铁剑 88 (1d8, 命中 +1) · 柳叶刀 96 · 雁翎刀 240 (1d10, 命中 +1) · 青锋剑 280 (1d10, 命中 +2) · 判官笔 200 (1d4, 命中 +3) | **换兵刃骰与命中** |
| 护具 | 短褐 40 (护体 +1) · 软甲 120 (+1 / 卸力 +1) · 护心镜 160 (护体 +1 / 卸力 +2) · 皮甲 180 (护体 +2) · 锁子甲 380 (护体 +3, 先攻 −1) | **护体 / 卸力** |
| 佩物 | 平安符 45 (气血上限 +5%) · 轻身符 70 (先攻 +2) · 铁牌 120 (暴击 +5) · 玉佩 90 (内力上限 +8%) | **上限 / 先攻 / 暴击** |
| 杂用 | 火折子 15 · 麻绳 12 (路上一类的坎 +1) · 名帖 30 (人那一类的坎 +1) | 只给**路上的坎**加值, 封顶 +2 |

**起步**: 60 文 + 铁剑 + 布衣 + 两包金创药 + 三包干粮 (`gear.START_*`)。
新人物与"读存档时发现没有这几栏"的老存档都补这一份。

## 4. 装具怎么进交手 (派生值, 不入库)

`charsheet.gear_mods(ch)` 是唯一入口 (内部调 `gear.mods`), 被两处读:

- `d20_stats()` 的拆账里各多一行 `src="gear"`:
  - 护体 AC += 护具 `ac`;  卸力 += 护具 `pierce`
  - 命中 += 兵器 `attack`;  **兵刃骰换成兵器自己的骰** (木剑 1d6 / 铁剑 1d8 / 雁翎刀 1d10)
  - 伤害 + 兵器 `damage`;  先攻 += 佩物 `init`;  暴击区间按 `combat.crit + 佩物 crit` 放宽
- `derive()` 的 `hp_max` / `neili_max` 吃佩物的 `hp_pct` / `neili_pct`

所以面板上那句「护体 14 · 1d10+16」与战报里的每一拍用的是同一套数, 战报里能看见
"这一下为什么中"。**换一件兵器不用迁移存档**: 存档里只有"身上是哪一件"。

## 5. 故事侧: 掷出来的账必须写出来

`_gear_brief()` 把这一趟的账交给写故事的那道工序 (`gear.before` / `gear.after` /
`gear.aftermath` / `gear.equipped`), `skills/adventure.md` 里有一条硬约定:

> 药与钱照输入写, **数额不许改**, 也不要写成清点 ("数了数, 共七十二文")。

并且**核正文** (`_gear_need` / `_gear_in_body`): 用了药 → 正文里要有"药 / 敷 / 郎中 / 医馆"
其中之一; 打了坐 → 要有"打坐 / 调息"。漏了这一回就**重写一次**; 两稿都漏 →
`gear_omitted` 记在账上 (页面标出来), 不装作没花。

**不强制**的两类 (免得为一句旁白整篇重写): 赏钱 / 脚钱 (写成"替人捎带东西"也说得通)、
捡到的战利品 (提了更好, 但不是它活下来的账)。

## 6. 页面上看得到什么

「行囊与银钱」卡 (`#card-bag`, 人物面板第二张):

- 页头徽标: 钱袋 (例 `75 文`)
- 摘要两行: 银钱 / 身上那三件的加成 / 医馆与客栈的价钱
- 三个装具槽 (兵器 / 护具 / 佩物) —— 空着的写"空着", 带着的可以直接卸下
- 折叠「行囊」: 逐行 名称 ×数量 · 效果 · 描述 · [用] [带上] [卖 N 文]
- 折叠「药铺 · 铁匠铺」: 28 样, 买不起的按钮是灰的

接口 (都在 `/pet/api/`): `GET /gear` · `POST /gear/{buy,use,sell,wear,unwear}`。
折价与拒绝都在服务端 (钱不够 / 带在身上卖不掉 / 没有这样东西)。

## 8. 边界 (写在这里, 免得下次又争论)

- **不做经济系统**: 没有物价波动、没有买卖议价、没有"存款利息"。钱只是"能不能上药"的门槛。
- **不卖已装备的东西**: 先卸下才能卖 (避免"卖掉了却还带着"的鬼状态)。
- **钱不够时不会欠账**: 自理时先看兜里有多少, 不够就退回打坐。
- **故事不能自己敷药、自己捡钱**: 账已在后端结完, 故事只是叙述。
- **强度上限**: 装具的加成是 d20 尺度的几个点 (命中 +3 / 护体 +3 / 骰子换一档),
  不让"买一把好剑"变成碾压 —— 本事的来源仍然是练出来的。
